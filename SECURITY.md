# Security policy

## Supported versions

Only the latest minor version of Typescape receives security fixes. A fix ships as a new patch release of that version.

## Reporting a vulnerability

Report vulnerabilities only through GitHub's [private vulnerability reporting](https://github.com/tamaslaszlototh/Typescape/security/advisories/new). Do not open a public issue, pull request or discussion about it.

Please include the Typescape version (`typescape --version`), your OS and .NET SDK version, and the steps to reproduce.

Typescape is maintained by one person on a best-effort basis. There is no guaranteed response or fix time, but every report is read and answered.
